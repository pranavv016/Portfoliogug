# Pranav Chauhan — Portfolio

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge, or another browser.
3. Keep the `assets` folder beside `index.html` so certificate images load.

## Publish with GitHub Pages
1. Create a GitHub repository (or use an existing portfolio repository).
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. In the repository, open Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
5. Open the GitHub Pages URL shown there.

Edit `index.html` to update text, projects, links, and skills.
